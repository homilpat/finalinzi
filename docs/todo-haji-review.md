# haji 브랜치 검토 후 할 일

검토 기준: Flask 서버(`giukhaji`) + Android 앱(`FinalProjectApp`)

`mobile_sensor_app` Expo 프로젝트와 `TTSTest`는 운영 파이프라인에서 제외한다.

## P0 - 배포 전 반드시 수정

- [ ] 미완료 검사 결과 확정 방지
  - 재현: 검사 시작 직후 `/final-result`에 직접 접속하면 빈 답안이 0점으로 완료 처리된다.
  - 영향: 사용자가 실수로 결과 페이지를 열면 180일 재검사 제한에 걸릴 수 있다.
  - 완료 기준: 모든 필수 단계가 끝나기 전에는 결과를 저장하지 않고 현재 문항으로 복귀시킨다.

- [ ] Android 운동 센서의 예상 동작 전달 연결
  - 재현: `exercise.js`는 `startMeasurement()`만 호출하고 Android의 `setExpectedAction()`을 호출하지 않는다.
  - 영향: `MotionClassifier`의 `expectedAction`이 `null`이라 실제 센서 동작 판정이 발생하지 않는다.
  - 완료 기준: 각 운동 지시 구간마다 예상 동작을 전달하고 실기기에서 성공·실패 판정을 확인한다.

- [ ] 운영 데이터 영속 저장소 구성
  - 현재 SQLite DB는 `giukhaji/data/moca_demo.sqlite3`에 저장되며 Render 영구 디스크 설정이 없다.
  - 영향: 재배포나 인스턴스 재시작 시 회원, 보호자, 검사, 운동 기록이 유실될 수 있다.
  - 완료 기준: Render 영구 디스크 또는 운영 DB를 사용하고 재시작 후 데이터 보존을 검증한다.

## P1 - 주요 기능 및 보안

- [ ] 보행 모델 설명과 실제 모델 방향 일치
  - 데모의 위험 예시와 일부 특징 설명이 실제 모델 예측 방향과 반대다.
  - 완료 기준: 모델 메타데이터와 계수를 기준으로 설명을 다시 만들고 고정 입력 회귀 테스트를 추가한다.

- [ ] `/demo` 세션 오류 수정
  - 데모 진입 후 `/item`, `/submit`, `/continue_wait`에서 필요한 세션 메서드가 없어 500 오류가 발생한다.

- [ ] Android와 Flask의 기본 포트 통일
  - Android 기본값은 `5000`, `python app.py` 기본값은 `5001`이다.
  - README, Android 설정, Flask 실행값을 하나로 통일한다.

- [ ] 접근 비밀번호 사용 시 `/ping` 자동 탐색 보장
  - 현재 `ACCESS_PASSWORD`가 설정되면 `/ping`도 로그인 페이지로 이동해 Android 서버 검색이 실패한다.

- [ ] 모바일 자동 로그인 인증 강화
  - `/api/mobile/remember-login`은 전화번호만으로 회원 세션을 생성할 수 있다.
  - 일회용 토큰, 기기 등록 또는 별도 인증 절차를 적용한다.

- [ ] WebView 권한과 URL 범위 제한
  - 모든 웹 권한 요청을 자동 승인하지 않도록 변경한다.
  - 허용 서버 목록, 외부 URL 처리, 네이티브 브리지 노출 범위를 명시한다.

- [ ] 중복 제출 방지
  - 연속 음성·터치 입력이 들어오면 여러 `/submit` 요청이 문항을 중복 진행시킬 수 있다.
  - 클라이언트 단일 실행 처리와 서버 문항 토큰·멱등성 검증을 함께 적용한다.

## P2 - 노인 사용자 접근성 및 입력 안정성

- [ ] 화면 확대 허용
  - `base.html`의 `user-scalable=no`를 제거하고 확대 상태에서 레이아웃을 확인한다.

- [ ] 운영 화면에서 개발용 이동 기능 제거 또는 관리자 한정
  - `개발자 문항 건너뛰기`, `검사 건너뛰기`, 수동 보행 값·CSV 입력을 일반 사용자에게 노출하지 않는다.

- [ ] STT 반복·호출어 오염 실기기 회귀 시험
  - 한 결과 내부의 반복 단어, 여러 결과 사이의 중복, 호출어와 답변을 함께 말한 경우를 각각 시험한다.
  - 느린 발화, 긴 침묵, 사투리, 주변 TV 소리, 버튼 연타도 포함한다.

- [ ] GPS 최신성 및 정확도 검증
  - 마지막 위치의 기록 시각과 정확도를 확인하고 기준을 벗어나면 새 위치를 요청한다.
  - 도로명이나 시설명이 행정구역 답으로 선택되지 않게 한다.

- [ ] 서버 연결 실패 복구 화면
  - Android WebView에 오류 안내, 재시도, 서버 재탐색 경로를 제공한다.

- [ ] 고정 하단 메뉴와 펭트 버튼 겹침 점검
  - 작은 화면, 큰 글자, 키보드 표시 상태에서 본문과 답변 버튼을 가리지 않는지 확인한다.
